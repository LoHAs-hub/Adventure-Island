# 美術方向 v0.2：2D美式街頭塗鴉
狀態：風格與體驗優先級已確認；以下視覺細則為設計建議，待樣板具體化。
決策依據：decisions/ADR-001-street-art-auto-battle.md。

## 已確認的核心循環
自動戰鬥持續 → 看見掉落 → 查看／比較 → 鎖定、整理或換裝 → 角色能力立即更新 → 繼續觀察戰鬥。
優先級：戰利品、裝備管理、角色素質；其次轉蛋與升級演出。

## 視覺語言建議
- 粗實線輪廓、不規則切角、大面積平塗、硬邊偏移陰影，建立印刷海報與街頭貼紙的感覺。
- 標題、稀有掉落與關鍵按鈕可使用輕微傾斜、描邊字、印章或漫畫爆框。
- 詞條、比較表、百分比與角色素質保持水平、對齊與清楚字距；繁體中文數據正文使用可辨識字形，數字優先等寬排列。
- 噴漆、網點、撕紙與油墨紋理集中在外緣、標題或事件裝飾，讓密集數字背後保持平整。
- 一般動態用短促位移、壓下、蓋章；稀有掉寶可有一次重點跳出。大量持續閃爍與發光會削弱事件差異。
- Q版角色與幻想場景可以保留世界觀；街頭風格首先作用在介面、圖示和戰利品呈現。

## 色彩提案（未定案）
炭黑／暖白構成閱讀底色，高飽和黃或橘用於主要行動，再用少量青色作輔助。此處不固定色碼。
既有7階稀有度先維持對應關係，以色條、階級名稱與角標圖形共同辨識；主題裝飾不能讓所有物品看起來都像最高階。
危險、扣減與增益各有文字／符號／形狀提示，不能只靠紅綠色。
小字對比目標4.5:1，關鍵元件與大字3:1；實作時以最後色票測量。

## 優先畫面
1. 戰鬥中的裝備管理：戰鬥保持可見，管理區可開關；角色素質摘要常駐，完整來源可展開。
2. 戰利品：一般物品精簡累積；重要掉落以貼紙式通知突出名稱、部位與稀有度。點選能定位仍在背包的該件物品。
3. 裝備比較：目前／候選、穿戴後角色戰力差、重要能力差、套裝影響與行動按鈕。
4. 角色素質：總覽清楚分成輸出、生存、刷寶／輔助；摘要項目與分組依實際資料挑選，避免杜撰新數值。
5. 主選單及導航：使用同一元件規格，提供進入戰鬥與回到裝備整理的清楚入口。

## 布局提案（未定案）
兩種觀看狀態：戰鬥總覽、裝備整理。切換管理區不停止戰鬥。
大視窗可用戰鬥左／管理右；比較區與背包共同保持選取物件可見。較小桌機可採上戰鬥／下管理或收合次要區，需用樣板驗證。
Canvas維持原始邏輯座標與長寬比；不能直接把整張既有HUD縮小到難以閱讀。狀態、掉落與管理文字需獨立保有可讀尺寸。
不以每一幀重建整個管理DOM；新掉落不得使背包自動跳位、遺失選取或捲動位置。

## 戰鬥可讀性
自動遊戲需要容易觀察角色表現與刷寶成果，技能快捷鍵可較收斂；自動戰鬥狀態、HP與重要異常保留清楚位置。
重大危險／失敗狀態即時可見；一般時刻由掉落與成長回饋吸引注意，裝飾特效控制覆蓋。
普通傷害短促、暴擊較突出，技能名節制出現。稀有掉落通知不遮住危險區、角色與裝備操作。
低畫質仍保留危險邊界、稀有標籤、HP與必要狀態。

## 第一批樣板
同一角色與同一組裝備資料，製作：
- 主要／次要／危險／不可用按鈕、分頁、裝備卡、提示與稀有標籤。
- 戰鬥總覽與管理區展開的兩種布局。
- 普通物品／稀有物品通知，以及目前裝備／候選裝備比較。
色票、線寬、字級與尺寸在樣板後寫入正式規格。
