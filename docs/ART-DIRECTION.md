# 當前美術方向：v0.4 淺藍與平順粗線

使用者已接受粗硬程度與左右布局，要求線條更滑順、少外凸稜角、主色淺藍，並完成全版美術交接。方向見 ADR-001／ADR-002；v0.2黃橘色與切角提案、v0.3黃綠樣板僅保留於歷史版本。

保留2D美式街頭漫畫感：粗重文字、高對比平塗、2～4px外輪廓、短硬陰影。以圓角接筆、連續曲線、平整卡片改善閱讀；紋理收在邊緣。主色#B9DFF6，輪廓#202A32，冷白#F3F6F8；稀有度與危險提示有獨立語意。

主要循環為自動戰鬥持續 → 看見掉落 → 比較／整理 → 換裝 → 當前能力更新。桌機左戰鬥右管理，戰利品與素質優先。全遊戲其餘系統沿用同一套元件與線條。

完整且可執行的規格集中在 [ART-SPEC](../handoff/v0.4/ART-SPEC.md)、[ASSET-GUIDE](../handoff/v0.4/ASSET-GUIDE.md) 及 [COVERAGE](../handoff/v0.4/COVERAGE.csv)，避免多份文件相互衝突。樣板見 [v0.4](../design/mockups/v0.4/README.md)。即時換裝工程約束見 LIVE-GEAR.md。

原遊戲尚未修改。44個SVG與五頁樣板是實作參考，完整職業、變體、動作與正式系統由實作端完成。
