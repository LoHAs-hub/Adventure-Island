- 2D美式粗硬、街頭塗鴉；粗邊框、高對比色塊、具辨識度的文字。
- 自動戰鬥為主，掉寶、裝備整理與角色素質優先，其次轉蛋與升級等。
- 戰鬥持續時可整理與換裝，能力立即生效。

請以「持續戰鬥 → 查看掉落 → 比較裝備 → 整理／換裝 → 素質更新」作為主流程。從可見的戰鬥區與可開關的管理區設計布局，不因開啟管理而結束、重開或暫停關卡。
先製作第一批元件與布局樣板，明確標示示例數據。視覺方案需要清楚的繁體中文正文、對齊的數值、完整狀態；依最終確認樣板執行遊戲改版。

工程要點：
1. 統一裝備變更入口，正確更新SVD、statsOf、戰鬥實體、外觀及相關顯示。復用refreshP前核對HP／MP、升級、進化等差異。
2. 保持冷卻、怒氣、現有攻擊／投射物、場上狀態與正常升級行為；不產生換裝補血或預覽影響戰鬥。
3. 即時掉落以item.id追蹤，保持選取與捲動，批次操作鎖定確認目標。通知反映入包、自動分解與滿包處理結果。
4. 清楚呈現戰力及重要詞條差、套裝影響；復用既有計算。稀有不等於適合，戰力差不等於所有流派價值。
5. 自動戰鬥狀態／HP／危險資訊與重要掉寶保持可讀；高低畫質與不同桌機視窗均需驗證。
6. 房主與訪客同步沿用權威模型，不能只讓某端顯示更新。未測的模式明確記錄。
7. 保持現有掉率、攻擊判定、數值公式及獎勵規則，避免擴散到未要求系統。
