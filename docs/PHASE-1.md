# 第一階段：街頭風介面、自動戰鬥與即時裝備管理
狀態：使用者已確認風格、體驗優先級及即時換裝；具體布局與視覺細則進入樣板討論。遊戲尚未修改。

## 已確認範圍
2D美式粗硬、塗鴉街頭、高對比色塊、粗邊框與有辨識度的文字樣式。
優先看掉寶、整理裝備、觀察角色素質；戰鬥持續時可以換裝，立即影響能力。
本協作端整理需求、Prompt與檔案包，交由實作端執行。

## 交付順序建議
| 批次 | 內容 | 驗收重點 |
|---|---|---|
| 1A | 共用視覺元件、戰鬥總覽／管理展開布局樣板、裝備比較與素質摘要 | 街頭風辨識度、長字／大數值可讀、稀有度及操作層級 |
| 1B | 自動戰鬥中的裝備管理與能力同步 | 不停戰、不錯換、不免費重置；背包／實體／存檔一致 |
| 1C | 掉落通知、整理排序、HUD、傷害字與特效層級 | 清楚看見重要掉落、比較不中斷、角色和危險區可見 |
| 1D | 主選單及其餘第一階段入口套用元件 | 導航與術語一致、能回到當前流程 |

## 邊界
角色／場景全套重製、轉蛋與升級演出的大幅改版放在後續。這不影響本階段維持原有功能可用。
即時換裝需做功能調整；攻擊幀、掉率、數值公式與結算規則的其他改動不在目前需求中。
若改存檔或連線欄位，記錄遷移與雙端同步，不可僅以視覺截圖代替功能驗證。
