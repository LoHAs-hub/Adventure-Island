# 第一階段：介面與戰鬥可讀性

狀態：使用者已選定範圍；具體美術方向與實作規格待討論。這次提交保存基準與計畫，沒有修改遊戲。

## 工作項目與驗收草案
| 項目 | 入口 | 預期成果 | 驗收方式 |
|---|---|---|---|
| 介面層級 | :root、.panel、.btnc、.mini | 區分主要操作、次要操作、資訊、警告；金色保留給重要項目 | 主選單與養成頁前後截圖；文字對比與焦點檢查 |
| 養成頁首屏 | renderGrowth、renderChars | 壓縮重複摘要，優先呈現裝備與當前操作 | 1280×720、1440×900、1920×1080可操作；捲動可到全部內容 |
| 提示一致性 | rsTip、cmpTip、qhelp、toast | 共用提示樣式與層級，避免被遮住或超出遊戲區 | 視窗邊緣懸停、長文字、裝備比較與彈窗 |
| 戰鬥文字 | dFx、hud、fmtS | 傷害、暴擊、技能名稱、狀態資訊可分辨，不持續遮住主角 | 一般戰鬥與多敵密集畫面；不同畫質與職業 |
| 特效層級 | render、drawSlash/Sp/Ult、dPr、GQ | 主角、敵人輪廓與預警優先，特效保留重點 | 低／中／高畫質、普通技能與大絕，檢查預警可見性 |
| 戰鬥HUD | hud、hudClick、HUDA | 血量、冷卻、自動狀態清楚，點擊與顯示區域一致 | 縮放後點擊、自動切換、鎖定／可用／冷卻狀態 |

## 設計討論提案（尚未選定）
A. 保留黑金奇幻，減少裝飾與光暈，使用明確的卡片與字級層級。
B. 清爽冒險手冊，以明亮中性色面板、少量金色強調和章節插畫建立親切感。
C. 深色戰鬥面板，以深藍灰底、職業色與精簡框線突出操作與危險提示。
先以主選單、養成裝備頁、戰鬥畫面三個樣板比較，再決定實作。

## 修改邊界
本階段聚焦呈現；若涉及命中範圍、攻擊幀、冷卻、獎勵、存檔結構或連線欄位，須另記原因與回歸方案。
角色全套重製、場景全面翻新、轉蛋重製留待後續階段；必要的字體／圖示規範可先建立。
