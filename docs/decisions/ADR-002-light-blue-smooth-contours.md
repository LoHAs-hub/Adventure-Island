# ADR-002：淺藍、平順粗線與全版美術交接

日期：2026-11-09。狀態：使用者方向已確認，v0.4已具體化；正式遊戲待實作。

## 直接依據

使用者最新回饋：「粗硬程度OK，但希望線條再滑順一些，太多禿出的稜角，喜歡淺藍色，左右布局OK，依照這樣的方向修改一次全版美術，給我Prompt和檔案包轉交給實作端」。延續先前指定的本端整理需求／交接、實作端修改遊戲的分工。

## 決策

保留粗框、對比與街頭感，收斂外凸尖角與斜切，使用圓角接筆與連續曲線；淺藍作操作／選取主色。保留左戰鬥、右管理；即時整理／換裝與掉寶／素質優先不變。

將同一美術語言延伸至全遊戲 UI、提示、人物／敵人／夥伴、圖示、場景、動作、特效、掉落、轉蛋和事件演出。以分批順序實作，不將其他系統永久排除。

本次交付更新的獨立互動樣板、全版覆蓋矩陣、44個靜態SVG參考、設計tokens、Prompt、工程驗收、原始遊戲與Harness。正式遊戲依然保存原始位元；不可將本包稱為已完成遊戲改版。

## 設計落地值與影響

#B9DFF6／#202A32／#F3F6F8、12px面板圓角、2～4px粗線等為此次設計採用值，不是使用者逐值指定。實作可直接使用。稀有度與危險仍有獨立語意。v0.2的黃橘主色、不規則切角，以及v0.3等待布局確認的狀態由本決策取代。

主要風險仍是管理介面與戰鬥生命週期、能力快照、即時掉落／背包與連線權責。LIVE-GEAR仍生效；正式驗收見handoff/v0.4/ACCEPTANCE.md。
