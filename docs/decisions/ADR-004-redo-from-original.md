# ADR-004：原始基準重做

使用者明確拒絕d1942ae交付並要求重新執行。舊提交及文件證據保留作失敗嘗試歷史，所有本輪實作狀態重新計算。基準為重新上傳ZIP的3625d38，完整原HTML獨立保存。

以可維護的來源層／明確hook產出單檔，不採全域gradient替換或Proxy改寫Canvas。全新管理區直接讀取正式SVD／statsOf／cpWith，舊養成頁僅承載進階功能；主比較及操作不依賴捲到舊頁底部。各批證據必須核對樣板結構及功能，不能以有截圖當作設計品質完成。

全版重新繪製共用玩家／怪物／夥伴／世界入口，保留原座標、尺寸基礎、關節狀態／時序與資料變體。工程操作與美術改造分檔，打包保留原單檔離線方式。

預警採實際bossSp／hitBox幾何：落雷22→24的顯示深度與完整衝撞路徑均修正視覺，判定不動。M4測試以原函式演算邊界，非只截圖。主角首次冒險預設AUTO ON；其後保留使用者當次開關，沒有更改戰鬥數值。
