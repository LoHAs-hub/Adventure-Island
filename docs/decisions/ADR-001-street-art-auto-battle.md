# ADR-001：街頭塗鴉風格與自動戰鬥中的裝備管理
日期：2026-11-09
狀態：使用者明確確認

## 決策
1. 風格以「2D美式粗硬、類似塗鴉街頭」為主，採粗邊框、高對比色塊與文字樣式，追求辨識度。
2. 遊戲以自動戰鬥為主；優先體驗是看掉寶、整理裝備、觀察角色素質。轉蛋、升級等體驗排在其後。
3. 自動戰鬥持續時可整理、換裝，立即影響角色能力。使用者明確選擇了此選項，不能默認改為結算後才生效。
4. 本協作端負責設計、需求、Prompt與檔案包；遊戲實作交由實作端。

## 影響
- 第一階段優先設計「戰鬥＋戰利品＋裝備比較＋角色素質」的連續流程。
- 先前黑金奇幻／冒險手冊／深藍灰三個方向已被本決策取代。
- 顏色數值、字型、精確布局、掉落動畫時長尚未由使用者選定；細則標為設計建議。
- 即時換裝是功能需求，除了美術也需存檔、戰鬥實體、背包更新、輸入路由與連線一致性驗證。
- 此次方向不自動授權新增職業、改成都市題材、改數值平衡或重製所有角色。
