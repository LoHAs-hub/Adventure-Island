# ADR-003：正式戰鬥管理與同步

2026-11-10，實作選擇，非新增玩法。

原 m4 於同場戰鬥移至右側 aside，結束歸還原 DOM；整理不使用 show／toMenu。原 800×450、HUDA／座標換算不動。背包主動按「更新背包」顯示新到貨，掉落不重建管理 DOM；選取與批次操作以 ID 為準。滿包無任何未鎖定候選時出售本次新增物，修正原本回退索引 0 會出售鎖定物的缺陷。

正式持久提交 saveG 和自動潛能每次實際套用共用 syncEquipmentState，原 refreshP 保留 HP／MP 絕對值、進化 evH、冷卻、怒氣、死亡及快照投射物。預覽不提交不觸發同步。

網路各端自有 SVD，原遊戲並無伺服器背包帳本。新 gear 請求含角色、穿戴 ID、來源 profile／account、場次、單調版本；房主檢查身分／部位／重複 ID／等級／有限值後使用正式 statsOf 重算，不接受客端 st 當裝備更新。ACK 後訪客套用顯示，重送去重，舊場次忽略。房主自身變更另發 actorGear。

信任邊界仍為原本本機存檔：這不是防作弊系統，不能證明本機物品來源或升級成本。完整伺服器帳本／存檔簽章不在本次範圍；不得把這項限制描述為已實現物品權威驗證。雙分頁測試與外網 P2P 分開記錄。

M5補強：hello附上本機所有背包／穿戴物的ID清單；房主維護該清單與主機發出的loot，gear僅接受已知ID及相同部位／稀有度／物品等級／系列，升級限制範圍。這可擋住同場憑空新增ID；無法證明入房前本機存檔或本機強化隨機結果真偽。
