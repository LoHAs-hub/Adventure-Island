# 提供實作端的樣板閱讀Prompt

這份v0.3包含三頁互動樣板及五張狀態截圖。先閱讀DESIGN-NOTES.md與VALIDATION.md，了解哪些是已確認需求、哪些是待討論提案。

使用者已確認街頭塗鴉風格、自動戰鬥刷寶優先，以及不停戰整理／即時換裝。樣板的具體色票、布局、角色插圖與字級尚待回饋；請勿把「產出樣板」視為使用者已核准所有細節。

樣板源碼完全獨立於正式遊戲。正式基準為Adventure-Island的game/index.html（SHA見manifest.json），需求見docs/PHASE-1.md、ART-DIRECTION.md、LIVE-GEAR.md及ADR-001。
正式實作時，使用原遊戲計算和物品資料；保留生命、冷卻、怒氣和進行中的戰鬥；統一裝備變更刷新與連線同步。重用此樣板的視覺元件時，要保留工具列之外的正式遊戲內容，移除設計演示與假數據。

請先根據使用者對這三組樣板的回饋更新規格，再分批完成介面與功能，提供前後對照、功能測試證據與未測項。不要只交截圖，或宣稱HTML演示已完成原遊戲的即時換裝。
