# v0.4 美術規格

方向：有份量的 2D 街頭漫畫。以粗重字、平塗色塊、圓角粗框、短硬陰影建立辨識度。此次修正集中在「粗，但線順」。方向與左右布局由使用者確認；以下尺寸／色碼為可採用的設計落地值。

## 色彩與使用比例

| Token | 值 | 用途 |
|---|---|---|
| ink | #202A32 | 外輪廓、主文字、深色導覽 |
| paper | #F3F6F8 | 頁面底色、深色區的淺文字 |
| surface | #FBFCFD | 裝備表、數值、卡片內容 |
| primary | #B9DFF6 | 主要按鈕、選取標記、重點標題區 |
| primaryHover | #9DCEEC | 主要操作懸停 |
| primaryPressed | #86BDDF | 壓下狀態，實際值見 tokens |
| mutedText | #526775 | 次要說明，不用透明度壓低關鍵數值 |
| borderMuted | #C2CED5 | 表格分隔、非互動內線 |
| positiveText / positiveSurface | #245840 / #E1EFE8 | 能力增加、已套用，搭配 +／文字 |
| dangerText / dangerSurface | #8C303A / #F5D2D6 | 錯誤、危險操作、扣減，搭配 −／文字 |
| dangerSolid | #B93846 | 危險區重點與警示；搭配 paper 淺文字 |
| focus | #24658B | 鍵盤焦點外環 |

tokens 提供機器可讀色值。中性色占大面積，淺藍用於可操作與已選取的區域；一般頁面避免所有卡片同時亮藍。橘／紫／金等保留給稀有標籤與物件本色。

原 RAR 索引與名稱維持：0 普通 #C9CED6、1 精良 #5FE08F、2 稀有 #4EA8FF、3 史詩 #C77DFF、4 傳說 #FFAE1A、5 神話 #FF3D6E、6 天金 #FFE94D。使用色條＋名稱辨識；同色附近的「稀有」和「選取」靠固定位置、雙框與圓點區別。高稀有不代表能力一定增加。色條不直接充當小字顏色。

普通正文對比至少 4.5:1；大字／元件邊界至少 3:1。淺藍按鈕使用 ink 文字與 ink 外框，不能只靠淺藍與白底的差異。所有最終狀態需依真實底色量測。

## 線條、形狀與材質

- 外容器 3～4 CSS px、卡片 2～3 px、內線 1～1.5 px；主面板圓角 12 px、外框 16 px、按鈕 8 px、裝備格 7 px。不要將每種形狀都做成膠囊。
- 接筆使用 `stroke-linejoin:round`、`stroke-linecap:round`；Canvas 依邏輯座標與縮放設定，配合 save／restore 避免污染後續繪圖。輪廓曲線的切線要連續，少用連續折點硬湊曲線。
- 保留功能性刃尖、方向箭頭、水晶稜面；刪減多餘髮刺、齒狀爆框、外凸三角角標與大面積不規則斜切。NEW／已穿戴／鎖定標記放在卡片內部固定角落。
- 短陰影約 2～4 px、無大模糊；主輪廓保持完整。標題與數據維持水平，街頭感由字重、分層和少量印刷紋理表達。
- 網點／噴漆只放外緣與大面積裝飾，透明度約 4～8%；數值表、長文字、比較區背景保持乾淨。角色使用一層主要陰影與少量高光。

## 字級、數字與控制項

繁體中文用本地可用的 Noto Sans CJK TC／Microsoft JhengHei／PingFang TC／sans-serif；不依賴線上字型下載。標題 24～32 px／800～900；區塊標頭 16～20 px；正文 14～16 px；密集表格 12～14 px；輔助文字 11～12 px。樣板中的 8～10 px 規格標注屬設計檢視工具，不應搬進正式遊戲的核心資訊。

數字採 tabular-nums；同欄靠右，小數位一致。大數字保留原 fmtS 的萬／億規則，可展開精確值。長裝備名允許兩行或省略＋完整詳情，不能擠壓主操作。互動控制項至少 36 px 高；主要操作 40～44 px；僅圖示按鈕有文字替代與明確焦點。

按鈕有一般／懸停／按下／鍵盤焦點／不可用／處理中；不可用顯示原因。選取、已裝備、已鎖定與 NEW 是獨立狀態，不因共用一個顏色互相覆蓋。分頁除了顏色還有填色與字重差異。

## 左右布局與資訊層級

桌機預設戰鬥約 58%、管理約 42%，區域間距 16～20 px；以 v0.4 的關係為準，可按可讀性微調，不改成一個全遮罩裝備頁。戰場維持 16:9，800×450 邏輯座標不變。右側由背包／素質分頁、身上裝備、比較、固定換裝行動構成；下方常駐簡潔能力摘要。

- 左側戰鬥有自動狀態、HP／必要資源與明確低血量提示；戰場下方是掉落紀錄／當輪收益。危險提示優先於普通掉落裝飾。
- 右側背包依 item.id 固定選取；篩選、排序、鎖定不移走比較中的物件。新到貨先更新計數，排序策略不能讓滑鼠下的物品突然換人。
- 比較列列出目前值／換裝後／差值，包含降低項目。戰力差與條件說明分開；套裝門檻、等級不足、物品不存在均有真實狀態。
- 素質以輸出、生存、刷寶／輔助分組，僅呈現原遊戲可計算的項目，說明來源不捏造新計算。

驗收視窗 1280×720、1440×900、1920×1080。矮桌機保留左右關係，縮減次要留白／收益列表並讓管理內容局部捲動；主要換裝操作可達，HP／自動狀態持續可見。不要等比縮小所有文字來塞滿一屏。低於約 1000 px 可順序堆疊／收合；手機屬相容性檢視，不宣稱已完整設計觸控操作。樣板在 1280×720 需要垂直捲動，正式版須依以上規則整合。

## 動態、掉寶與戰鬥可讀性

一般 UI 過渡 100～160 ms、按下約 80～100 ms；重要掉落進場約 180～220 ms、停留約 2.5～3.5 秒，之後仍可從紀錄開啟。最高稀有可多一層短光帶，不能循環閃爍蓋住操作。這些是展示時間，不調整戰鬥幀。

一般掉落合併計數；重要掉落在固定安全區顯示名稱、部位、稀有度與真實去向。事件優先級為危險／死亡／斷線 > 操作結果 > 重要掉落 > 一般掉落彙整。危險出現時壓低非必要裝飾，不能犧牲操作命中區或遺失掉落紀錄。

戰場圖層：背景與環境 → 地面／陰影 → 與判定一致的預警填色 → 實體／掉落 → 攻擊與必要特效 → 高優先預警邊界／倒數 → HUD。實際可以依原程式拆層，結果必須讓預警邊界與主角可見。普通傷害短促，暴擊放大有限；技能名避免每次覆蓋角色。保持原判定、施法／攻擊時序與取值方式。

技能用連續弧線／圓弧拖尾，命中以短線、簡單環形擴散。低畫質可減粒子、模糊與裝飾光暈，保留預警、HP、技能就緒、稀有標籤、地面互動與敵我識別。維持原無戰鬥鏡頭震動；支援 reduced-motion 時縮減裝飾，不改戰鬥模擬。

## 全版系統與素材

封面、主選單、挑戰、養成、寵物／神獸、任務、收藏、戰地、設定與連線共用上述標頭、分頁、卡片、按鈕與彈窗；原頁面內容依原邏輯顯示，不搬入規格卡示例資料。轉蛋以圓弧光帶與圓角結果卡延伸，保留跳過、批量結果、再抽與去向顯示，避免高頻全屏白閃。

角色、怪物、夥伴、場景與圖示的完整清單、已附資產／待製作差異見 ASSET-GUIDE.md。逐項代碼入口和驗收見 COVERAGE.csv。
